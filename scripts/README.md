# 📜 scripts/
Colección de scripts de automatización para tareas de mantenimiento y procesamiento masivo.

## Contenido
- **`clean_logs.py`**: Limpieza de directorios temporales y logs de entrenamiento acumulados.
- **`export_results.py`**: Generación de paquetes de datos para compartir resultados experimentales.
- **`setup_env.sh`**: Script opcional para preparar el entorno de dependencias y datasets iniciales.

## Uso en el Experimento
Herramientas auxiliares operadas fuera de Streamlit para la gestión higiénica del sistema y la exportación de descubrimientos.
