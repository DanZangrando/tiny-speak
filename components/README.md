# 🧩 components/
Piezas reutilizables de la interfaz de Streamlit y visualizaciones especializadas.

## Contenido
- **`modern_sidebar.py`**: El menú de navegación lateral que centraliza el estado del proyecto y parámetros globales.
- **`analytics.py`**: Componentes para mostrar gráficas de entrenamiento, matrices de confusión e informes de clasificación.
- **`diagrams.py`**: Generador de esquemas de redes neuronales (Graphviz) para la documentación interactiva.
- **`code_viewer.py`**: Utilidades para mostrar el código fuente de los modelos directamente en la web.

## Uso en el Experimento
Centraliza el diseño visual y la UX de la aplicación, permitiendo que todas las páginas de Streamlit mantengan la misma estética "premium" y funcionalidades compartidas.
